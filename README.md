# 📰 반도체 뉴스 스크랩북

읽은 반도체 뉴스를 **날짜 · 제목 · 관련 회사 · 한 줄 메모 · 중요도(★)** 와 함께 기록하고,
검색 · 정렬 · 통계로 다시 볼 수 있는 웹 프로그램입니다.
1주차에 만든 C++ 콘솔 프로그램을 생성형 AI(Claude)와 함께 웹으로 옮겼습니다.

## 🔗 바로 사용하기

**https://jaehohwang990114-code.github.io/semicon-news-scrapbook/**

PC와 스마트폰 브라우저에서 모두 쓸 수 있습니다. 설치나 회원가입은 필요 없습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 뉴스 추가 | 날짜, 기사 제목, 회사, 메모, 중요도(★ 클릭)를 입력하고 **추가하기** |
| 회사 자동 추천 | 제목에 "하이닉스", "TSMC" 같은 이름이 있으면 회사가 자동 선택됨 |
| 목록 · 검색 | 키워드(제목·메모), 회사, 최소 중요도로 걸러 보기 · 최신순/중요도순 정렬 · 검색어 하이라이트 |
| 수정 · 삭제 | 각 뉴스의 **수정** / **삭제** 버튼 |
| 회사별 통계 | 회사별 스크랩 수 막대그래프, 평균 중요도, 가장 많이 스크랩한 회사 |
| Google 뉴스 | 검색어로 최신 뉴스 10건을 받아서 골라 스크랩 (원문 링크 포함) |
| 파일 저장 · 불러오기 | `news_scrap.txt` 형식 (C++ 버전과 호환) |
| 다크 모드 | 오른쪽 위 🌙 버튼 |

## 사용 방법

1. 위 주소에 접속합니다. 처음이면 **예시 뉴스 5건 넣어 보기**로 기능을 둘러볼 수 있습니다.
2. 왼쪽(스마트폰은 위쪽) 입력 폼에 뉴스를 적고 **추가하기**를 누릅니다.
3. **📋 목록 · 검색** 탭에서 검색창과 선택 상자로 원하는 뉴스를 찾습니다.
4. **📊 회사별 통계** 탭에서 어느 회사 뉴스를 많이 모았는지 확인합니다.
5. **🔎 Google 뉴스** 탭에서 검색 → **스크랩** → 회사·별점·메모 입력 → **스크랩북에 저장**.

> 💾 데이터는 **내 브라우저에만** 저장됩니다(localStorage). 다른 기기로 옮기려면 **파일로 저장** 후 다른 기기에서 **파일 불러오기**를 하세요.
>
> 🔎 Google 뉴스는 브라우저 보안 정책(CORS) 때문에 공개 중계 서버(allorigins)를 거쳐 가져옵니다. 중계 서버가 바쁘면 실패할 수 있으니 잠시 후 다시 시도하거나, PC에서 `node server.js`(또는 `실행.bat`)로 실행해 http://localhost:8080 에서 쓰면 내 PC가 직접 가져옵니다.

## 파일 구성

```
index.html   웹 프로그램 (HTML + CSS + JavaScript, 파일 하나)
server.js    PC용 로컬 서버 — Google 뉴스 RSS 중계 (Node.js, 설치할 패키지 없음)
실행.bat     server.js 를 더블클릭으로 실행
cpp/         1주차 C++ 콘솔 버전 원본 소스
```
